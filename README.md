## 🥋 VR-Based Autism Therapy & Movement Analysis

One of my biggest projects combines:

**Virtual Reality + Machine Learning + Movement Analysis + Healthcare**

The system was designed to support motor imitation training for children with Autism Spectrum Disorder.

### Main components

- VR training environment developed using Unity
- Movement capture and comparison
- AI-based movement similarity analysis
- Siamese Transformer architecture
- FastAPI inference service
- Behavioral assessment
- Participant feedback and scoring

The goal was to compare a participant's movement with expert reference movements and generate an imitation score and feedback.

### Tech

`Python` `PyTorch` `Transformers` `FastAPI` `Unity` `VR`

This project taught me a lot about building systems where AI is only one part of a much larger application.

## 🎮 AI-Based Autism Screening Game
